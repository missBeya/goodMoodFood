# Good Mood Food

Good Mood Food is a mood-based food recommendation web application developed as my B.Sc. (Hons) Computer Science (Software Engineering) project at the University of Hull.

The project explores how a user's selected mood can be used to provide relevant food recommendations through a simple and responsive web experience.

## Features

- Mood-based food recommendation interface
- User authentication with Firebase Authentication
- Firebase integration for application data
- Responsive user interface built with HTML, CSS and JavaScript
- Client-side interaction and application logic
- Prototype backend routing and database integration explored during development

## Project Structure

The repository includes:

- `public/` — public-facing application resources
- `scripts/` — client-side JavaScript
- `controllers/` — controller logic developed during the project
- `Routes/` — application routing
- `Config/` — configuration
- `images/` — application assets
- `firebase-config.js` — Firebase client configuration
- `server.js` — backend prototypes explored during development

## Engineering Approach

This project was developed through requirements analysis, implementation and testing as part of my final-year Software Engineering work.

During development, I explored authentication, database integration, client-server communication, routing and the interaction between frontend and backend components.

The project also gave me practical experience in functional and usability testing and helped shape the architectural decisions used in the next version of Good Mood Food.

## Evolution of the Project

I am currently rebuilding Good Mood Food using **Java, Spring Boot and PostgreSQL**, with a stronger focus on separation of concerns, REST API design, maintainability, secure configuration, testing and deployment practices.

This original repository is retained as the first version of the application and as a record of its technical evolution.
